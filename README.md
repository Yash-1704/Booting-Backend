# 🚀 Backend Learning

A collection of my backend development learning, practice, and experiments.

This repository covers the concepts and technologies I’m learning while working through backend development, from writing basic servers and APIs to databases, authentication, real-time communication, caching, and deployment.

## 🧠 What I'm Learning

### 🟢 Node.js & Express.js

Node.js fundamentals, npm, HTTP servers, Express.js, routing, middleware, REST APIs, file handling, and backend architecture.

### 🗄️ Databases

MongoDB, Mongoose, database relationships, MongoDB Atlas, indexing, query optimization, and aggregation.

### 🔐 Authentication & Security

Authentication, authorization, JWT, sessions, cookies, password hashing, validation, sanitization, CORS, and API security.

### ⚡ APIs & Backend Development

REST API design, API versioning, HTTP methods, status codes, error handling, Postman, and API testing.

### 💬 Real-Time & Performance

WebSockets, Socket.IO, Redis, caching, and performance-related concepts.

### 📝 Logging & Testing

Logging, monitoring, debugging, code formatting, and backend testing.

### 🐳 Production & Deployment

Production configuration, Linux, PM2, Docker, AWS, CI/CD, deployment, scalability, and reliability.

### 🏗️ Advanced Concepts

Microservices, API gateways, event-driven architecture, message queues, observability, and system-design concepts.

## 🎯 Focus

The main focus is on learning backend development by writing code, building APIs, working with databases, and understanding how backend systems are structured and deployed.
